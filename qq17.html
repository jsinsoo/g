서술형 17 | 부정적분의 비밀, 열다섯의 빛

원본 문제 17

원본 문제는 중복하지 않고 이미지로 한 번만 제시합니다.

풀이의 핵심

부정적분의 적분상수는 초기조건을 통해 결정합니다.

\[F(x)=\int(3x^2+4x-1)\,dx=x^3+2x^2-x+C\]
\[F(0)=1\Rightarrow C=1\Rightarrow\boxed{F(2)=15}\]

12단계 디딤돌 · 논리적 손풀이

01조건 읽기

\[f(x)=3x^2+4x-1,\quad F(0)=1\]

F는 f의 한 부정적분이므로 F′(x)=f(x)입니다.

02부정적분의 뜻

\[F\prime(x)=f(x)\]

미분하면 f가 되는 함수 F를 찾습니다.

03항별 적분

\[\int(3x^2+4x-1)\,dx\]

합의 적분은 각 항을 적분한 결과의 합입니다.

04첫째 항 적분

\[\int 3x^2\,dx=x^3\]

거듭제곱의 적분법을 적용합니다.

05둘째 항 적분

\[\int 4x\,dx=2x^2\]

x의 지수 1을 2로 높이고 계수를 2로 나눕니다.

06셋째 항 적분

\[\int (-1)\,dx=-x\]

상수 -1의 부정적분은 -x입니다.

07적분상수 포함

\[F(x)=x^3+2x^2-x+C\]

부정적분에는 반드시 적분상수 C를 포함합니다.

08초기조건 대입

\[F(0)=0+0-0+C=1\]

x=0을 넣으면 나머지 항은 모두 0입니다.

09적분상수 결정

\[C=1\]

초기조건을 만족하는 원시함수 하나가 정해집니다.

10함수 완성

\[F(x)=x^3+2x^2-x+1\]

구한 상수를 식에 대입합니다.

11목표값 계산

\[F(2)=2^3+2\cdot 2^2-2+1=15\]

거듭제곱과 곱셈부터 계산합니다.

12미분과 정적분으로 검산

\[F\prime(x)=3x^2+4x-1,\quad F(2)-F(0)=\int_0^2 f(x)\,dx=14\]

미분 결과가 원래 함수와 같고 15−1=14이므로 정답을 확인합니다.

그림 1 · 원래 함수와 원시함수

빨간 곡선은 원시함수 F이며, (0,1)과 (2,15)를 지납니다. 파란 곡선은 F의 기울기인 f입니다.

그림 2 · 정적분은 부호 있는 넓이

\[\int_0^2 f(x)\,dx=F(2)-F(0)=15-1=14\]

곡선이 x축 아래에 있는 부분은 음의 넓이로 계산합니다.

파이썬으로 해석하고 검산하기

SymPy로 적분상수를 결정하고 Matplotlib으로 두 그래프를 그립니다. Windows IDLE에서 실행할 수 있습니다.

import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

x = sp.symbols('x', real=True)
f = 3*x**2 + 4*x - 1
F_general = sp.integrate(f, x) + sp.Symbol('C')
C = sp.solve(sp.Eq(F_general.subs(x, 0), 1), 'C')[0]
F = sp.expand(F_general.subs('C', C))

print('원래 함수 f(x) =', f)
print('적분상수 C =', C)
print('원시함수 F(x) =', F)
print('F(2) =', F.subs(x, 2))
print('미분 검산 =', sp.simplify(sp.diff(F, x) - f))
print('정적분 검산 =', sp.integrate(f, (x, 0, 2)))

xs = np.linspace(-1.5, 3.2, 500)
f_np = sp.lambdify(x, f, 'numpy')
F_np = sp.lambdify(x, F, 'numpy')
plt.figure(figsize=(10, 6))
plt.plot(xs, f_np(xs), label='f(x)', linewidth=2)
plt.plot(xs, F_np(xs), label='F(x)', linewidth=2)
plt.scatter([0, 2], [1, 15], color='red', zorder=5)
plt.annotate('F(0)=1', (0, 1), xytext=(10, 10),
             textcoords='offset points')
plt.annotate('F(2)=15', (2, 15), xytext=(10, -20),
             textcoords='offset points')
plt.axhline(0, color='gray', linewidth=0.8)
plt.axvline(0, color='gray', linewidth=0.8)
plt.grid(alpha=0.25)
plt.legend()
plt.tight_layout()
plt.savefig('math17_graph.png', dpi=180)
plt.show()

예상 출력

원래 함수 f(x) = 3*x**2 + 4*x - 1
적분상수 C = 1
원시함수 F(x) = x**3 + 2*x**2 - x + 1
F(2) = 15
미분 검산 = 0
정적분 검산 = 14

실생활 활용 · 누적 변화량

예를 들어 어떤 저장 탱크의 순유입률을 f(t)=3t²+4t−1 (L/분)으로 모델링하고 초기 저장량이 1L라면, 2분 후 저장량은 15L입니다. 유입률이 음수인 구간은 유출이 더 큰 상황을 나타냅니다.

\[\text{2분 후 저장량}=1+\int_0^2(3t^2+4t-1)\,dt=15\text{ L}\]

실생활 사례는 수학적 원리를 설명하기 위해 만든 가상 모델입니다.
