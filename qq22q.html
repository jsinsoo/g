22번 문제: 숫자 여행을 떠나요!

어려운 수식보다 먼저, 숫자가 움직이는 규칙을 알아봐요.

① 원래 문제 보기

문제는 첫 번째 숫자 a₁를 찾으라는 뜻이에요. 숫자를 차례로 여섯 번째까지 만들었을 때 세 번째 숫자와 여섯 번째 숫자가 같아야 해요.

② 숫자가 움직이는 두 가지 규칙

홀수: 1, 3, 5, 7…

1을 더하고 → 반으로 나누고 → 순서 번호 더하기

예: 숫자 7이 첫째 자리라면

(7+1)÷2+1 = 5

짝수: 2, 4, 6, 8…

지금 숫자에 순서 번호만 더하기

예: 숫자 8이 첫째 자리라면

8+1 = 9

⭐ 순서 번호는 지금 있는 자리예요. 첫째에서 둘째로 갈 때 +1, 둘째에서 셋째로 갈 때 +2, …, 다섯째에서 여섯째로 갈 때 +5!

③ 숫자 여행 직접 해보기

④ 15와 25는 어떻게 발견할까요? (추측하지 않는 수학 탐정)

처음에는 15도 25도 모릅니다! 세 번째 숫자를 x라고 부르고, 세 번 움직인 뒤 같은 x가 되는 숫자를 찾습니다.

우리의 목표

a₃ = x → a₄ → a₅ → a₆ = x

세 번째에서 네 번째로 갈 때는 3, 네 번째에서 다섯 번째는 4, 다섯 번째에서 여섯 번째는 5를 더합니다.

탐정 1. x가 짝수라면?

x가 짝수 → a₄ = x+3 (홀수) → a₅ = (x+4)÷2+4 = x÷2+6

길 ① a₅가 짝수라고 가정: x = a₅+5 = x÷2+11 → x=22. 그런데 a₅=17은 홀수! 가정과 어긋나므로 탈락.

길 ② a₅가 홀수라고 가정: x = (a₅+1)÷2+5 = (x+14)÷4+5 → 4x=x+34 → x=34÷3. 자연수가 아니므로 탈락.

따라서 x는 짝수일 수 없습니다.

탐정 2. x가 홀수라면?

x가 홀수 → a₄ = (x+1)÷2+3 = (x+7)÷2. 이제 a₄의 홀짝을 살펴봅니다.

탐정 2-A. a₄가 짝수

a₅ = a₄+4 = (x+15)÷2

길 ③ a₅도 짝수: x=a₅+5=(x+15)÷2+5 → 2x=x+25 → x=25.

직접 확인: 25 → 16 → 20 → 25 (홀수→짝수→짝수). 모든 조건과 일치하므로 성공!

길 ④ a₅가 홀수: x=(a₅+1)÷2+5=(x+17)÷4+5 → 4x=x+37 → x=37÷3. 자연수가 아니므로 탈락.

탐정 2-B. a₄가 홀수

a₅ = (a₄+1)÷2+4 = (x+25)÷4

길 ⑤ a₅가 짝수: x=a₅+5=(x+25)÷4+5 → 4x=x+45 → x=15.

직접 확인: 15 → 11 → 10 → 15 (홀수→홀수→짝수). 모든 조건과 일치하므로 성공!

길 ⑥ a₅가 홀수: x=(a₅+1)÷2+5=(x+29)÷8+5 → 8x=x+69 → x=69÷7. 자연수가 아니므로 탈락.

발견! 가능한 셋째항은 딱 두 개

a₃ = a₆ = 15 또는 25

짝수에서 출발하는 2가지 길과 홀수에서 출발하는 4가지 길, 총 6가지 길을 모두 확인했기 때문에 다른 숫자는 없습니다.

탐정 3. 이제 거꾸로 첫째항을 찾아요

앞으로 가는 규칙을 거꾸로 사용해요. 다음 숫자가 b이고, 더했던 순서 번호가 n이라면:

이전 숫자가 짝수였다면

이전 숫자 = b − n

결과가 짝수일 때만 인정!

이전 숫자가 홀수였다면

이전 숫자 = 2(b − n) − 1

결과가 홀수일 때만 인정!

④ 정답 하나를 천천히 따라가기

첫 숫자를 24라고 해 볼까요?

1칸: 24는 짝수 → 24+1 = 25
2칸: 25는 홀수 → (25+1)÷2+2 = 15
3칸: 15는 홀수 → (15+1)÷2+3 = 11
4칸: 11은 홀수 → (11+1)÷2+4 = 10
5칸: 10은 짝수 → 10+5 = 15

세 번째 숫자 15 = 여섯 번째 숫자 15! 🎉

⑦~⑨ 정말 네 개뿐인지 확인하는 탐정 놀이

1부터 1000까지 시험하는 것은 좋은 검산이에요. 하지만 1001 이상의 숫자에 답이 없다는 것까지 알려 주지는 못해요. 그래서 수학 탐정은 거꾸로 따라가는 8가지 길을 조사해요.

⑦ 왜 8가지 길인가요?

세 번째에서 네 번째, 네 번째에서 다섯 번째, 다섯 번째에서 여섯 번째로 갈 때마다 홀수 길 또는 짝수 길을 선택해요. 따라서 2×2×2 = 8가지예요.

⑨ 세 번째 숫자에서 첫 번째 숫자로 거꾸로 가기

성공한 세 번째 숫자는 15 또는 25예요. 거꾸로 계산해 보면 둘째 숫자는 25 또는 45예요.

둘째 숫자가 25가 되는 첫째 숫자는 24 또는 47이고, 둘째 숫자가 45가 되는 첫째 숫자는 44 또는 87이에요.

예를 들어 첫째 숫자가 홀수이면 (첫째+1)÷2+1=25이므로 첫째=47이에요. 짝수이면 첫째+1=25이므로 첫째=24예요.

⑩ 파이썬으로 한 칸씩 계산해 보기

아래 코드는 홀수인지 짝수인지, 어떤 계산을 했는지 모두 출력해요. 마지막에는 1~1000을 검사해 답을 확인해요.

def next_term(a, n):
    if a % 2 == 1:
        b = (a + 1) // 2 + n
        rule = f"({a}+1)÷2+{n} = {b}"
        kind = "홀수"
    else:
        b = a + n
        rule = f"{a}+{n} = {b}"
        kind = "짝수"
    print(f"{n}번째 → {n+1}번째: {a}({kind}), {rule}")
    return b

def trace(first):
    print("\n첫째항:", first)
    seq = [first]
    for n in range(1, 6):
        seq.append(next_term(seq[-1], n))
    print("전체 수열:", seq)
    print("a3 == a6 ?", seq[2] == seq[5])

for first in [24, 44, 47, 87]:
    trace(first)

# 컴퓨터 검산: 1부터 1000까지
solutions = []
for first in range(1, 1001):
    seq = [first]
    for n in range(1, 6):
        a = seq[-1]
        seq.append((a + 1)//2 + n if a % 2 else a + n)
    if seq[2] == seq[5]:
        solutions.append(first)
print("성공한 첫째항:", solutions)
print("합계:", sum(solutions))
