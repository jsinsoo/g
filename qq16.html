서술형 16 · 시그마의 비밀

원본문항 · 10단계 손풀이 · 수학 그림 · 파이썬 검산 · 실생활 활용 · 풀이의 노래

원본 수학 문제

원본문항은 이미지로 한 번만 제시합니다.

풀이의 핵심

각 항에 1씩 더했으므로 총합에는 7이 추가되었습니다. 원래 합은 23이고, 모든 항을 3배한 합은 69입니다.

\[\sum_{k=1}^7 a_k=30-7=23,\qquad \sum_{k=1}^7 3a_k=3\times23=\boxed{69}\]

10단계 디딤돌 · 징검다리 손풀이

01 문제의 조건 읽기

\[\sum_{k=1}^{7}(a_k+1)=30\]

수열의 일곱 항 각각에 1을 더한 값들의 총합이 30이라는 뜻입니다.

02 시그마 기호 해석

\[(a_1+1)+(a_2+1)+\cdots+(a_7+1)=30\]

시그마는 시작 인덱스부터 끝 인덱스까지 차례로 더하라는 기호입니다.

03 덧셈의 교환·결합법칙 적용

\[(a_1+\cdots+a_7)+(1+\cdots+1)=30\]

수열의 항끼리 모으고, 1끼리 모아도 합은 바뀌지 않습니다.

04 시그마의 선형성 이용

\[\sum_{k=1}^{7}(a_k+1)=\sum_{k=1}^{7}a_k+\sum_{k=1}^{7}1\]

합의 분배법칙을 이용하여 두 개의 시그마로 나눕니다.

05 상수항 합 계산

\[\sum_{k=1}^{7}1=7\]

k가 1부터 7까지 움직이므로 1을 정확히 일곱 번 더합니다.

06 수열 항들의 합 구하기

\[\sum_{k=1}^{7}a_k+7=30\]

주어진 30에서 추가된 7을 제거해야 원래 수열의 합이 됩니다.

07 원래 합 확정

\[\sum_{k=1}^{7}a_k=30-7=23\]

개별 항의 값은 몰라도 합 23은 유일하게 결정됩니다.

08 상수배 법칙 적용

\[\sum_{k=1}^{7}3a_k=3\sum_{k=1}^{7}a_k\]

모든 항을 3배하면 전체 합도 3배가 됩니다.

09 정답 계산

\[3\times23=69\]

찾는 값은 69입니다.

10 검산과 일반화

\[\sum_{k=1}^{n}(ca_k+d)=c\sum_{k=1}^{n}a_k+nd\]

항이 n개일 때 상수 d는 n번 더해집니다. 이 문제는 n=7, c=1, d=1입니다.

그림으로 이해하기

파란 영역은 원래 수열의 합, 주황 영역은 각 항에 추가된 1의 합입니다. 영역의 길이는 개념적 표현입니다.

막대그래프는 조건을 만족하는 예시 수열 [1, 2, 3, 4, 5, 6, 2]를 사용합니다. 실제 수열이 이 값으로 정해지는 것은 아닙니다.

파이썬 코드로 해석하고 검산하기

Python IDLE 또는 Colab에서 실행합니다. numpy, matplotlib이 필요합니다.

# 서술형 16번: 시그마 합의 성질과 검산
import numpy as np
import matplotlib.pyplot as plt

# 조건을 만족하는 예시 수열 (유일한 수열이 아님)
a = np.array([1, 2, 3, 4, 5, 6, 2])
assert len(a) == 7

original_sum = 30 - 7
answer = 3 * original_sum
print('Σ(a_k + 1) =', sum(a + 1))
print('Σa_k =', original_sum)
print('Σ3a_k =', answer)
assert sum(a + 1) == 30
assert sum(3 * a) == 69

k = np.arange(1, 8)
plt.figure(figsize=(10, 5))
plt.bar(k - 0.2, a, width=0.4, label='a_k')
plt.bar(k + 0.2, a + 1, width=0.4, label='a_k + 1')
plt.xticks(k)
plt.xlabel('k')
plt.ylabel('Value')
plt.title('Sum of 7 terms: 23 + 7 = 30')
plt.legend()
plt.grid(axis='y', alpha=0.2)
plt.tight_layout()
plt.show()

Σ3a_k = 69

실생활 활용 — 7일간의 생활비 기록

예를 들어 7일 동안 매일 1천 원씩 수수료가 추가된 총지출이 3만 원이었다면, 원래 지출 합계는 3만 원 − 7천 원 = 2만 3천 원입니다.

같은 지출이 3배로 늘어나는 상황을 가정하면 총액은 6만 9천 원입니다. 이는 시그마의 상수항과 상수배 법칙을 활용한 가상 사례입니다.
