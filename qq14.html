서술형 14 · 원에 내접한 사각형의 둘레

원본문항 · 12단계 논리적 손풀이 · 그림 · 파이썬 검증 · 실생활 응용

원본 문제

핵심 도형과 논리

반지름 3인 원에 내접한 사각형입니다. 먼저 사인법칙으로 대각선 BD를 구하고, 마주 보는 각의 합이 180°라는 사실로 AD를 구합니다. 마지막으로 이등변삼각형 BCD에서 BC와 CD를 구합니다.

\[p=4\sqrt2,\quad q=\frac{2\sqrt6}3,\quad r=2\sqrt6\]

정답 ① √2

12단계 디딤돌 · 징검다리 풀이

01 조건 읽기

\[R=3,\quad AB=3AD,\quad BC=CD,\quad \cos\angle DCB=\frac13\]

원의 반지름과 세 조건을 각각 확인합니다.

02 코사인의 부호

\[\angle DCB=\arccos\frac13\]

코사인 값이 양수이므로 이 각은 예각입니다.

03 사인 값 계산

\[\sin\angle DCB=\sqrt{1-\frac19}=\frac{2\sqrt2}{3}\]

삼각함수의 기본 관계식을 사용합니다.

04 사인법칙으로 대각선

\[p=BD=2R\sin\angle DCB=6\cdot\frac{2\sqrt2}{3}=4\sqrt2\]

BD는 삼각형 BCD에서 각 DCB의 대변입니다.

05 원에 내접한 사각형

\[\angle BAD+\angle BCD=180^\circ\]

원에 내접한 사각형의 마주 보는 두 각은 보각입니다.

06 다른 각의 코사인

\[\cos\angle BAD=-\cos\angle BCD=-\frac13\]

보각의 코사인 부호는 반대입니다.

07 삼각형 ABD의 코사인법칙

\[BD^2=AB^2+AD^2-2(AB)(AD)\cos\angle BAD\]

AB=3AD를 대입할 준비를 합니다.

08 AD 구하기

\[32=9q^2+q^2+2q^2=12q^2\ \Rightarrow\ q=\sqrt{\frac83}=\frac{2\sqrt6}{3}\]

선분 길이는 양수이므로 양의 제곱근을 택합니다.

09 삼각형 BCD의 코사인법칙

\[BD^2=r^2+r^2-2r^2\cdot\frac13=\frac43r^2\]

BC=CD=r을 사용합니다.

10 BC와 CD 구하기

\[32=\frac43r^2\ \Rightarrow\ r^2=24\ \Rightarrow\ r=2\sqrt6\]

길이 r도 양수입니다.

11 요구한 값 계산

\[\frac{qr}{p}=\frac{\frac{2\sqrt6}{3}\cdot 2\sqrt6}{4\sqrt2}=\frac8{4\sqrt2}=\sqrt2\]

분모를 유리화하면 최종 값이 나옵니다.

12 둘레 및 검산

\[P=4q+2r=\frac{20\sqrt6}{3},\qquad \frac{qr}{p}=\boxed{\sqrt2}\]

원문의 둘레 식과 답을 함께 검증합니다.

파이썬으로 계산하고 그리기

아래 코드는 numpy와 matplotlib을 사용합니다. IDLE에서 실행하려면 pip install numpy matplotlib로 설치합니다.

import math
import numpy as np
import matplotlib.pyplot as plt

R = 3
angle_C = math.acos(1/3)
p = 2*R*math.sin(angle_C)
q = math.sqrt(p*p/12)
r = math.sqrt(3*p*p/4)
print('p =', p, 'q =', q, 'r =', r)
print('q*r/p =', q*r/p)
print('둘레 =', 4*q + 2*r)

# 원 위의 네 꼭짓점: 반시계방향 B-C-D-A
angle0 = -math.pi/2
delta = 2*math.asin(r/(2*R))
angles = {
    'B': angle0-delta,
    'C': angle0,
    'D': angle0+delta,
    'A': angle0+delta+2*math.asin(q/(2*R))
}
points = {n: np.array([R*math.cos(t), R*math.sin(t)])
          for n,t in angles.items()}
fig, ax = plt.subplots(figsize=(7, 7))
t = np.linspace(0, 2*np.pi, 600)
ax.plot(R*np.cos(t), R*np.sin(t), color='royalblue')
for u, v in [('A','B'),('B','C'),('C','D'),('D','A')]:
    X, Y = points[u], points[v]
    ax.plot([X[0],Y[0]], [X[1],Y[1]], color='crimson', lw=2)
X, Y = points['B'], points['D']
ax.plot([X[0],Y[0]], [X[1],Y[1]], '--', color='gray')
for n, (x,y) in points.items():
    ax.scatter(x,y,color='black')
    ax.annotate(n,(x,y),xytext=(7,7),textcoords='offset points')
ax.set_aspect('equal')
ax.grid(alpha=.2)
ax.set_title('Cyclic quadrilateral ABCD, radius = 3')
plt.show()

검산 결과: p ≈ 5.656854, q ≈ 1.632993, r ≈ 4.898979, qr/p ≈ 1.414214.
