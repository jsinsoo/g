공통 풀이 전략

홀수인 항은 절반으로 줄어드는 식을, 짝수인 항은 덧셈식을 적용합니다. 먼저 \(a_3=a_6\)을 만족하는 \(a_3\) 후보를 찾고, \(a_2\), \(a_1\)을 거꾸로 구해 모든 자연수 해를 찾습니다.

각 문항의 상한은 단순히 추측한 범위가 아닙니다. \(x=a_3\), \(M=\max(c,d)\)라 할 때 세 번의 진행 중 적어도 한 번 홀수 분기가 발생합니다. 세 번 모두 짝수 분기라면 \(a_6>x\)이기 때문입니다. 첫 홀수 분기 이전의 증가량과 그 이후의 증가량을 합쳐 \(a_6\le (x+c)/2+12+3M\)이므로 \(a_6=x\)이면 \(x\le c+24+6M\)입니다. 각 문항은 이 상한보다 큰 범위까지 검사합니다.

수식은 인터넷 연결 시 MathJax로 선명하게 표시됩니다. 인터넷이 없는 경우에는 수식 원문이 표시될 수 있습니다.

파이썬 완전 검산 코드 (10문항 공통)

아래 코드를 Python IDLE 또는 Colab에 붙여 넣으면 각 문항의 수열과 정답을 확인할 수 있습니다.

cases = [(1,1),(1,2),(1,3),(3,0),(3,1),
         (3,2),(3,3),(5,0),(5,1),(5,2)]

def next_term(a, n, c, d):
    if a % 2:
        return (a + c) // 2 + n
    return a + n + d

def predecessors(y, n, c, d):
    for x in [y - n - d, 2 * (y - n) - c]:
        if x > 0 and next_term(x, n, c, d) == y:
            yield x

for idx, (c, d) in enumerate(cases, 1):
    bound = c + 24 + 6 * max(c, d)
    solutions = set()
    for a3 in range(1, bound + 1):
        a4 = next_term(a3, 3, c, d)
        a5 = next_term(a4, 4, c, d)
        a6 = next_term(a5, 5, c, d)
        if a3 != a6:
            continue
        for a2 in predecessors(a3, 2, c, d):
            for a1 in predecessors(a2, 1, c, d):
                solutions.add((a1, a2, a3, a4, a5, a6))
    solutions = sorted(solutions)
    print(f"문항 {idx}: c={c}, d={d}")
    for row in solutions:
        print("  ", row)
    print("a1의 합:", sum(row[0] for row in solutions))
