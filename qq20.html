서술형 20 — 지수함수와 로그함수의 닮음

원본문항 · 12단계 손풀이 · 그림 · 파이썬 코드 · 실생활 연결

원본 수학 문제

풀이의 핵심

서로 역함수인 지수함수와 로그함수는 y=x에 대해 대칭입니다. 평행선 위에 놓인 닮은 삼각형의 대응 관계를 분석하면 네 점의 좌표가 결정됩니다.

\[\boxed{a^2=27}\]

01 역함수 관계 확인

\[g(x)=f^{-1}(x)\]

지수함수와 로그함수의 정의를 비교하면 서로 역함수입니다.

02 교점 B, C의 대칭

\[B=(v,f(v)),\quad C=(f(v),v)\]

직선 y=-x+2/3은 y=x에 대한 반사로 자기 자신으로 옮겨집니다. 지수함수와 로그함수의 교점 B, C는 서로 대칭입니다. 두 곡선은 각 직선과 한 번씩 만나므로 이 대응이 유일합니다.

03 직선 위의 점 좌표

\[A=(u,-u-\tfrac23),\quad D=(-\tfrac23,0)\]

A는 아래쪽 직선과 지수함수의 교점이고 D는 아래쪽 직선의 x절편입니다.

04 닮음의 대응 순서

\[\triangle CBA\sim\triangle BAD\]

C↔B, B↔A, A↔D입니다. 따라서 CB↔BA, BA↔AD가 대응합니다.

05 평행선과 직각

\[BC\parallel AD,\qquad BA\perp AD\]

CB와 AD는 기울기 −1인 평행선입니다. 대응하는 두 각을 비교하면 BA는 이 평행선들에 수직이어야 합니다(비퇴화 삼각형).

06 점 B의 가로좌표

\[v-u=\tfrac23\]

BA의 기울기가 +1입니다. A, B의 y좌표 차이를 이용하면 v−u=2/3입니다.

07 한 변수로 표현

\[A=(-t-\tfrac23,t),\quad B=(-t,t+\tfrac23)\]

t>0을 A의 y좌표로 두면 B의 좌표도 결정됩니다.

08 역함수 대칭으로 C 결정

\[C=(t+\tfrac23,-t)\]

B의 x, y좌표를 서로 바꾸면 C입니다.

09 세 선분의 길이

\[BA=\tfrac{2\sqrt2}{3},\quad AD=\sqrt2t,\quad BC=\sqrt2(2t+\tfrac23)\]

좌표 사이의 거리를 피타고라스 정리로 구합니다.

10 닮음비로 방정식 세우기

\[BA^2=BC\cdot AD\;\Rightarrow\;t(2t+\tfrac23)=\tfrac49\]

CB:BA=BA:AD이므로 BA의 제곱은 BC와 AD의 곱입니다.

11 양수 해 선택

\[9t^2+3t-2=(3t+2)(3t-1)=0\Rightarrow t=\tfrac13\]

t>0이므로 t=−2/3은 제외합니다. 따라서 B=(−1/3,1)입니다.

12 지수함수에 대입

\[1=\sqrt3a^{-1/3}\Rightarrow a^{1/3}=\sqrt3\Rightarrow\boxed{a^2=27}\]

a>1 조건에도 맞고, 모든 좌표와 닮음 조건을 만족합니다.

파이썬으로 그린 정확한 그래프

그래프의 실제 좌표: A(−1, 1/3), B(−1/3, 1), C(1, −1/3), D(−2/3, 0).

파이썬 SymPy 계산 및 Matplotlib 시각화

import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

a = 3*sp.sqrt(3)
A = (-1, sp.Rational(1,3))
B = (-sp.Rational(1,3), 1)
C = (1, -sp.Rational(1,3))
D = (-sp.Rational(2,3), 0)

def distance(P,Q):
    return sp.sqrt((P[0]-Q[0])**2+(P[1]-Q[1])**2)

print('a^2 =', sp.simplify(a**2))
print('AB^2 =', sp.simplify(distance(A,B)**2))
print('BC*AD =', sp.simplify(distance(B,C)*distance(A,D)))
print('f(B_x) =', sp.simplify(sp.sqrt(3)*a**B[0]))
print('g(C_x) =', sp.simplify(sp.log(C[0]/sp.sqrt(3),a)))

x = np.linspace(-2.5, 1.2, 500)
z = np.linspace(.08, 2.1, 500)
av = float(a)
plt.figure(figsize=(9,6))
plt.plot(x, np.sqrt(3)*av**x, label='f(x)')
plt.plot(z, np.log(z/np.sqrt(3))/np.log(av), label='g(x)')
plt.plot(x, -x-2/3, '--', label='lower line')
plt.plot(x, -x+2/3, '--', label='upper line')
for name, p in {'A':A,'B':B,'C':C,'D':D}.items():
    px, py = map(float,p)
    plt.scatter(px,py)
    plt.annotate(name,(px,py),xytext=(5,6),textcoords='offset points')
plt.xlim(-2.5,2.1)
plt.ylim(-2.2,2.3)
plt.gca().set_aspect('equal')
plt.grid(alpha=.25)
plt.legend()
plt.tight_layout()
plt.savefig('math20_graph.png',dpi=160)
plt.show()

예상 출력: a² = 27, AB² = 8/9, BC×AD = 8/9, f(Bₓ)=1, g(Cₓ)=−1/3.

실생활 활용 — 역함수와 기하학적 설계

복리 성장이나 미생물 증식은 지수함수로 모델링하고, 목표값에 도달하는 시간은 로그함수로 역산할 수 있습니다. 닮음비는 측량·도면 축척·구조물의 치수 검증에 활용됩니다. 이는 개념의 응용 사례이며 문제 속 수치 자체가 실측 자료인 것은 아닙니다.
