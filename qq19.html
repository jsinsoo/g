서술형 19 · 삼차함수의 최댓값과 최솟값

원본 문제 19

원본 문제 이미지는 한 번만 제시합니다.

풀이의 핵심

\[f(0)=6,\quad f(1)=6-a,\quad f(2)=6+4a\]

닫힌구간에서 최댓값·최솟값 후보를 구한 뒤 두 경우를 비교합니다.

\[a=-2,\qquad\boxed{f(-2)=62}\]

12단계 디딤돌 손풀이

01 문제의 조건 읽기

\[f(x)=2ax^3-3ax^2+6,\quad 0\le x\le 2\]

최댓값 8, 최솟값 −2는 반드시 닫힌구간의 함수값 중에서 나옵니다.

02 닫힌구간의 극값 원리

\[\text{후보: 양 끝점과 구간 내부의 }f\prime(x)=0\text{인 점}\]

다항함수는 연속이므로 닫힌구간에서 최댓값과 최솟값이 존재합니다.

03 도함수 계산

\[f\prime(x)=6ax^2-6ax=6ax(x-1)\]

미분법을 적용하고 공통인수 6ax를 묶습니다.

04 상수 a가 0이 아님

\[a=0\Rightarrow f(x)=6\]

a=0이면 최댓값과 최솟값이 모두 6이므로 주어진 조건에 어긋납니다.

05 극값 후보 확인

\[f\prime(x)=0\Rightarrow x=0\ \text{또는}\ x=1\]

구간 안의 임계점 1과 양 끝점 0, 2를 검사합니다.

06 세 함수값 계산

\[f(0)=6,\quad f(1)=6-a,\quad f(2)=6+4a\]

원래 함수에 차례대로 대입합니다.

07 6은 최댓값도 최솟값도 아님

\[-2<6<8\]

따라서 8과 −2는 f(1), f(2)에 하나씩 배정되어야 합니다.

08 첫 번째 경우 검토

\[6-a=8\Rightarrow a=-2,\quad 6+4a=-2\]

이 경우 세 값은 6, 8, −2로 정확히 조건에 맞습니다.

09 두 번째 경우 배제

\[6-a=-2\Rightarrow a=8,\quad f(2)=38\ne 8\]

반대로 배정하면 최대 8이라는 조건에 모순됩니다.

10 함수식 완성

\[a=-2\Rightarrow f(x)=-4x^3+6x^2+6\]

조건을 만족하는 상수는 유일하게 −2입니다.

11 구간 밖의 값 계산

\[f(-2)=-4(-8)+6(4)+6=32+24+6\]

−2는 [0,2] 밖이지만 다항함수는 모든 실수에서 정의되므로 대입할 수 있습니다.

12 최종 검산

\[\boxed{\min_{[0,2]}f=-2,\quad\max_{[0,2]}f=8,\quad f(-2)=62}\]

x=1에서 8, x=2에서 −2임을 확인하고 최종 답 62를 얻습니다.

그림 1. 삼차함수와 최댓값·최솟값

파란 음영은 문제에서 최댓값과 최솟값을 판단하는 구간 [0, 2]입니다. 왼쪽의 x=-2는 계산하려는 구간 밖의 점입니다.

그림 2. 실생활 활용 예시

센서의 측정값, 생산량, 기계의 높이 변화 등을 일정 시간 구간에서 분석할 때도 끝점과 내부 임계점을 모두 비교합니다. 그림은 원리 설명용 가상 자료이며 실제 측정 데이터는 아닙니다.

파이썬 SymPy · Matplotlib 계산과 그래프

import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

x, a = sp.symbols('x a', real=True)
f = 2*a*x**3 - 3*a*x**2 + 6
fp = sp.diff(f, x)
print('도함수:', sp.factor(fp))
print('후보 함수값:', [sp.expand(f.subs(x, t)) for t in [0, 1, 2]])

# 두 배정 경우를 모두 확인합니다.
for first, last in [(8, -2), (-2, 8)]:
    for av in sp.solve(sp.Eq(f.subs(x, 1), first), a):
        vals = [sp.simplify(f.subs({a: av, x: t})) for t in (0, 1, 2)]
        print('a =', av, '후보값 =', vals,
              '조건 충족 =', min(vals) == -2 and max(vals) == 8)

answer_f = sp.expand(f.subs(a, -2))
print('완성된 함수:', answer_f)
print('f(-2) =', answer_f.subs(x, -2))

# 함수 그래프 및 최대·최소 표시
xx = np.linspace(-2.4, 2.5, 600)
yy = -4*xx**3 + 6*xx**2 + 6
plt.figure(figsize=(10, 6))
plt.plot(xx, yy, label='f(x)=-4x^3+6x^2+6')
plt.axvspan(0, 2, color='skyblue', alpha=0.2)
for px, py, label in [(0,6,'(0,6)'),(1,8,'max (1,8)'),
                      (2,-2,'min (2,-2)'),(-2,62,'f(-2)=62')]:
    plt.scatter(px, py)
    plt.annotate(label, (px,py), xytext=(6,7),
                 textcoords='offset points')
plt.grid(alpha=0.3)
plt.legend()
plt.xlabel('x')
plt.ylabel('f(x)')
plt.savefig('math19_graph.png', dpi=160, bbox_inches='tight')
plt.show()

예상 출력의 핵심

도함수: 6*a*x*(x - 1)
a = -2 후보값 = [6, 8, -2] 조건 충족 = True
a = 8 후보값 = [6, -2, 38] 조건 충족 = False
완성된 함수: -4*x**3 + 6*x**2 + 6
f(-2) = 62

실생활 연결과 주의할 점

어떤 시간 구간에서 기계의 높이나 센서의 출력이 가장 크고 작은 시점을 찾을 때 도함수의 영점만 보는 것은 부족합니다. 반드시 구간의 양 끝점도 확인해야 합니다. 이 문제에서 x=-2는 극값을 찾는 구간 밖이지만 함수값은 계산할 수 있습니다.

최종 정답: 62
