서술형 22 · 홀짝에 따른 점화식

원본 문제 22

풀이의 핵심

세 번째 항부터 시작하여 홀짝 분기를 완전히 분석하고, 가능한 첫째 항을 역으로 찾습니다.

\[a_1\in\{24,44,47,87\},\qquad\boxed{\sum a_1=202}\]

01조건 읽기

\[a_{n+1}=\begin{cases}\frac{a_n+1}{2}+n &(a_n\text{ odd})\\a_n+n &(a_n\text{ even})\end{cases}\]

모든 항은 자연수이며, 홀짝에 따라 다음 항이 달라집니다.

02되풀이되는 값 확인

\[a_3=a_6\]

세 번의 점화식 적용 뒤 원래 값으로 돌아오는 조건입니다.

03중간항을 미지수로

\[a_3=m\quad(m\in\mathbb N)\]

a₁부터 무작정 계산하기보다 a₃에서 시작해 경우를 좁힙니다.

04홀짝 분기표 작성

\[a_4=T_3(m),\quad a_5=T_4(a_4),\quad a_6=T_5(a_5)\]

Tₙ(u)는 u가 홀수이면 (u+1)/2+n, 짝수이면 u+n입니다.

05세 번의 홀짝 조합 검토

\[2^3=8\]

a₃, a₄, a₅의 홀짝 조합은 최대 8가지입니다. 가정한 홀짝과 결과가 맞는지도 확인해야 합니다.

06가능한 a₃ 구하기

\[\boxed{a_3\in\{15,25\}}\]

8개 경우를 조사하면 정수 후보 15, 18, 22, 25 등이 나오지만, 홀짝 검증까지 통과하는 것은 15와 25뿐입니다.

07첫 번째 순환 확인

\[15\to11\to10\to15\]

n=3,4,5를 순서대로 적용합니다: (15+1)/2+3=11, (11+1)/2+4=10, 10+5=15.

08두 번째 순환 확인

\[25\to16\to20\to25\]

n=3,4,5를 순서대로 적용합니다: (25+1)/2+3=16, 16+4=20, 20+5=25.

09a₂를 거꾸로 찾기

\[a_3=\frac{a_2+1}{2}+2\ \Longrightarrow\ a_2=2a_3-5\]

a₂가 짝수라면 a₂=a₃−2는 홀수가 되어 모순입니다. 따라서 a₂는 홀수이며 25 또는 45입니다.

10a₁의 모든 후보 찾기

\[a_1=a_2-1\quad\text{또는}\quad a_1=2a_2-3\]

a₁이 짝수이면 a₂=a₁+1, 홀수이면 a₂=(a₁+1)/2+1입니다.

11네 가지 수열 검산

\[a_1\in\{24,44,47,87\}\]

각 시작값을 실제 점화식에 넣어 a₃=a₆인지 확인합니다.

12합 구하기

\[24+44+47+87=\boxed{202}\]

문제가 요구하는 모든 가능한 첫째항의 합은 202입니다.

수열 변화 그래프

네 가지 수열 모두 세 번째 항과 여섯 번째 항의 값이 같습니다. 선은 항 사이의 변화를 시각적으로 연결한 것입니다.

파이썬으로 해석하고 검산하기

# 문제 22: 홀짝 조건에 따른 수열을 정확하게 검산

def next_term(a, n):
    if a % 2 == 1:
        return (a + 1) // 2 + n
    return a + n

solutions = []
for first in range(1, 1000):
    seq = [first]
    for n in range(1, 6):
        seq.append(next_term(seq[-1], n))
    if seq[2] == seq[5]:
        solutions.append((first, seq))

for first, seq in solutions:
    print(f'a1={first:2d}, a1~a6={seq}')
print('첫째항의 합 =', sum(first for first, _ in solutions))
# 출력: 202
# 위 반복 범위는 계산 검산용이며, 모든 자연수에 대한 완전성은 손풀이의 경우 분석으로 증명합니다.

실생활 활용 예시

재고 관리나 컴퓨터 상태 전이에서 조건에 따라 다른 규칙을 적용한다는 아이디어와 연결됩니다. 실제 재고 관리 규칙이 이 문제의 점화식과 동일하다는 뜻은 아닙니다.
