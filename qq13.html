문제 13 · 원본 문항

핵심 결론

$$f(x)=\frac14x^2+x-3,\qquad f(4)=\boxed{5}$$

정답: ③ 5

12단계 디딤돌·징검다리 손풀이

01조건 이해

$$f'(0)=1,\qquad f(x)=(f'(x)+2)(f'(x)-2)$$

도함수의 초기값과 함수·도함수 사이의 항등식을 확인합니다.

02곱셈공식 적용

$$f(x)=\bigl(f'(x)\bigr)^2-4$$

합차공식 (u+2)(u−2)=u²−4를 사용합니다.

03양변을 미분

$$f'(x)=2f'(x)f''(x)$$

연쇄법칙을 적용합니다. 도함수의 제곱을 미분하면 2f′(x)f″(x)입니다.

04한쪽으로 이항

$$f'(x)\bigl(2f''(x)-1\bigr)=0$$

모든 실수 x에서 성립하는 다항식 항등식입니다.

05영다항식의 곱 성질

$$f'(0)=1\ne0\quad\Longrightarrow\quad 2f''(x)-1\equiv0$$

주의: 각 x에서 f′(x)≠0이라고 나누는 것은 잘못입니다. 다항식의 곱이 영다항식이라는 성질로 결론을 얻습니다.

06이계도함수 구하기

$$f''(x)=\frac12$$

두 번째 인수가 모든 x에서 0입니다.

07적분으로 일계도함수 구하기

$$f'(x)=\frac{x}{2}+C$$

상수항 C는 초기 조건으로 정합니다.

08초기 조건 대입

$$1=f'(0)=C\quad\Longrightarrow\quad f'(x)=\frac{x}{2}+1$$

x=0을 대입하여 적분상수를 확정합니다.

09원래 항등식에 대입

$$f(x)=\left(\frac{x}{2}+1\right)^2-4=\frac14x^2+x-3$$

적분상수를 별도로 구할 필요 없이 처음 주어진 식에 대입합니다.

10구하려는 값 계산

$$f(4)=\frac14\cdot16+4-3=\boxed5$$

보기 ③을 선택합니다.

11미분으로 검산

$$f'(x)=\frac{x}{2}+1,\quad f'(0)=1$$

초기 조건이 정확히 맞습니다.

12항등식으로 검산

$$\bigl(f'(x)+2\bigr)\bigl(f'(x)-2\bigr)=\left(\frac{x}{2}+1\right)^2-4=f(x)$$

모든 x에서 원래 조건이 성립하므로 풀이가 완성됩니다.

그림으로 보는 풀이

첨부한 풀이 인포그래픽을 학습용 참고 그림으로 수록했습니다. 엄밀한 다항식 항등식 논증은 위 5단계를 참고하세요.

함수와 도함수의 그래프

포물선은 함수값을, 직선은 변화율을 나타냅니다. x=4에서 함수값은 5입니다.

파이썬으로 계산·검산·시각화

Windows IDLE에서 실행할 수 있습니다. 필요한 라이브러리: sympy, numpy, matplotlib

import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

x = sp.symbols('x', real=True)
fprime = x/2 + 1
f = sp.expand(fprime**2 - 4)

print('f\'(x) =', fprime)
print('f(x) =', f)
print('f\'(0) =', fprime.subs(x, 0))
print('f(4) =', f.subs(x, 4))
print('원래 조건 검산 =', sp.simplify(f - (fprime+2)*(fprime-2)))

xs = np.linspace(-5, 6, 500)
ys = sp.lambdify(x, f, 'numpy')(xs)
vs = sp.lambdify(x, fprime, 'numpy')(xs)
plt.figure(figsize=(9, 6))
plt.plot(xs, ys, label='f(x) = x²/4 + x - 3', linewidth=2)
plt.plot(xs, vs, label="f'(x) = x/2 + 1", linewidth=2)
plt.scatter([4], [5], s=70)
plt.annotate('(4, 5)', (4, 5), xytext=(8, 8), textcoords='offset points')
plt.axhline(0, color='gray', linewidth=.8)
plt.axvline(0, color='gray', linewidth=.8)
plt.grid(alpha=.3)
plt.legend()
plt.show()

예상 실행 결과

f'(x) = x/2 + 1
f(x) = x**2/4 + x - 3
f'(0) = 1
f(4) = 5
원래 조건 검산 = 0

실생활 응용 — 수학적 모형의 예

운동: 위치를 이차함수로 근사하면 도함수는 순간속도를 뜻합니다. 비용 분석: 총비용의 도함수는 한 단위 증가에 따른 한계비용으로 해석할 수 있습니다. 데이터 모델링: 관측된 관계를 이차함수로 근사해 변화율과 예측값을 살펴볼 수 있습니다.

이 문제의 함수는 수학적으로 정해진 예시이며 실제 운동·비용 데이터를 나타낸 것은 아닙니다.
