서술형 18 — 파도의 가장 낮은 곳에서, 일곱의 빛을 찾아서

원본문항 · 12단계 손풀이 · 그래프 · 파이썬 검산 · 실생활 응용

원본 수학 문제

원본문항은 중복 표기하지 않고 위 이미지만 제시합니다.

풀이의 핵심

사인함수의 범위는 \(-1\leq\sin t\leq1\)입니다. 진폭 4, 수직 이동 a인 함수의 최솟값은 \(a-4\)입니다.

\[a-4=1\ \Longrightarrow\ a=5\]
\[\boxed{f(\pi/2)=7}\]

01 문제의 조건 정리

\[f(x)=4\sin\left(x-\frac{\pi}{3}\right)+a,\quad \min f(x)=1\]

최솟값이 주어졌으므로 먼저 상수 a를 결정합니다.

02 사인함수의 기본 범위

\[-1\leq\sin t\leq1\]

모든 실수 t에서 성립하는 기본 성질입니다.

03 각도의 이동 확인

\[t=x-\frac{\pi}{3}\]

x가 모든 실수를 움직이면 t도 모든 실수를 움직입니다.

04 진폭 4의 의미

\[-4\leq4\sin\left(x-\frac{\pi}{3}\right)\leq4\]

양수 4를 곱하면 최솟값은 -4입니다.

05 수직 이동 a 적용

\[a-4\leq f(x)\leq a+4\]

상수 a를 더하면 그래프 전체가 위아래로 이동합니다.

06 최솟값 조건 대입

\[a-4=1\]

문제에서 최솟값이 1이라고 주었습니다.

07 상수 a 결정

\[\boxed{a=5}\]

양변에 4를 더합니다.

08 함수식 완성

\[f(x)=4\sin\left(x-\frac{\pi}{3}\right)+5\]

최솟값 1, 최댓값 9, 중심선 y=5입니다.

09 x에 π/2 대입

\[f\left(\frac{\pi}{2}\right)=4\sin\left(\frac{\pi}{2}-\frac{\pi}{3}\right)+5\]

구하려는 함수값을 식에 직접 대입합니다.

10 분모를 통일하여 계산

\[\frac{\pi}{2}-\frac{\pi}{3}=\frac{3\pi-2\pi}{6}=\frac{\pi}{6}\]

각도의 차이를 정확하게 정리합니다.

11 특수각의 사인값

\[\sin\frac{\pi}{6}=\frac12\]

30도의 사인값은 1/2입니다.

12 최종 계산 및 검산

\[\boxed{f\left(\frac{\pi}{2}\right)=4\cdot\frac12+5=7}\]

7은 최솟값 1과 최댓값 9 사이에 있어 타당합니다.

함수 그래프 — 파이썬으로 시각화

곡선의 최솟값은 1, 최댓값은 9, 중심선은 \(y=5\)입니다. \(x=\pi/2\)에서 점 \((\pi/2,7)\)을 확인할 수 있습니다. 최솟값이 나타나는 한 점은 \((11\pi/6,1)\)입니다.

파이썬 코드 — SymPy 계산과 Matplotlib 그림

import numpy as np
import sympy as sp
import matplotlib.pyplot as plt

x = sp.symbols('x', real=True)
a = sp.solve(sp.Eq(-4 + sp.Symbol('a'), 1), sp.Symbol('a'))[0]
f = 4*sp.sin(x-sp.pi/3) + a
print('a =', a)
print('f(x) =', f)
print('f(pi/2) =', sp.simplify(f.subs(x, sp.pi/2)))
print('minimum =', a-4, ', maximum =', a+4)

xs = np.linspace(-np.pi/2, 3*np.pi, 800)
ys = 4*np.sin(xs-np.pi/3) + float(a)
plt.figure(figsize=(10, 5))
plt.plot(xs, ys, label='f(x) = 4sin(x-pi/3)+5')
plt.axhline(5, linestyle='--', label='midline y=5')
plt.axhline(1, linestyle=':', label='minimum y=1')
plt.scatter([np.pi/2, 11*np.pi/6], [7, 1])
plt.annotate('(pi/2, 7)', (np.pi/2, 7), xytext=(10,10), textcoords='offset points')
plt.annotate('(11pi/6, 1)', (11*np.pi/6, 1), xytext=(-70,-20), textcoords='offset points')
plt.grid(alpha=0.3)
plt.legend()
plt.tight_layout()
plt.savefig('math18_graph.png', dpi=160)
plt.show()
